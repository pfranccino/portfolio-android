# portfolio-android

Mi portafolio como app Android, construido desde cero y en público.

Es el proyecto de la serie **Detrás de la pantalla**: cada semana explico con dibujos una pieza de esta app, en Instagram ([@pfranccinodev](https://www.instagram.com/pfranccinodev/)).

## Lo que viene

El capítulo 1 es sobre Gradle. Después vienen, entre otras piezas, los módulos, la arquitectura, la inyección de dependencias y la navegación.

El código de cada capítulo va a quedar acá. Y cuando algo se rompa, también.
